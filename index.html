ABOUT TUNEWAVE

Good music.
More room to breathe.

TuneWave is an independent music interface and player. It searches Audius through its documented REST API and Jamendo through a server-side bridge. Jamendo tracks link to the source page so listeners can inspect the track-specific licence. Nuclear is a separate desktop player and does not expose its plugin catalogue as a public streaming API for this hosted website. Nuclear is a desktop player with a plugin API, not a hosted public music catalogue for website visitors, so it is not represented as a TuneWave provider. Song identification records a short microphone sample and sends it to TuneWave’s configured backend recognition endpoint; a valid AudD token and supported backend route are required.

✓
Audius + Jamendo web music

Search results combine Audius and Jamendo tracks. Jamendo uses a developer client ID on the server-side bridge, and each track's licence remains attached to its source page.

i
Why Nuclear is not a website provider

Nuclear's plugin API is for the running desktop app. It does not provide a public hosted catalogue and browser-stream API for all TuneWave visitors. Audius + Jamendo is the supported web architecture instead.

✓
Identify music you hear

Records up to 10 seconds from your microphone and asks the configured recognition service to identify it. This requires microphone permission and a valid recognition service credential.

✓
Listening controls

Lock-screen and headset controls appear when your browser/device supports Media Session.

✓
Local library

Favorites, recent tracks, and playback position are saved in this browser only.

Song availability and rights vary by provider. Jamendo's API terms permit non-commercial use by default; commercial/ad-supported projects must request terms from Jamendo. Inspect each Jamendo track's licence on its source page. Internet Archive results are limited to items marked Creative Commons or public domain, but verify each item's rights before reuse. The Archive is not a catalogue of current commercial hits. Nuclear remains a desktop companion rather than a provider inside TuneWave. TuneWave does not add its own ads, but cannot guarantee third-party streams are always available or ad-free. Background and lock-screen controls depend on browser/device support.
