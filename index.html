ABOUT TUNEWAVE

Good music.
More room to breathe.

TuneWave is an independent music interface and player. It searches Audius, Free To Use, Jamendo, Funkwhale / Open Audio, Internet Archive, Wikimedia Commons, ccMixter, Openverse, and Radio Browser through public APIs or TuneWave’s server-side bridge. Funkwhale / Open Audio adds a searchable catalogue of publicly playable uploads from an independent music federation; anonymous access depends on the instance settings. Connection status does not guarantee that every query returns a playable track. Source links and licence metadata are shown where available. Nuclear is a separate desktop player and does not expose its plugin catalogue as a public streaming API for this website. Song identification records a short microphone sample and sends it to TuneWave’s configured recognition endpoint; a valid AudD token and supported backend route are required.

✓
Searchable open-audio catalogues

Search results combine Audius, Free To Use, Jamendo, Funkwhale / Open Audio, Internet Archive, Wikimedia Commons, ccMixter, Openverse, and Radio Browser. Funkwhale searches public playable uploads from the Open Audio instance; access depends on the instance allowing anonymous reads. Free To Use does not require an API key or listener account. Jamendo uses a developer client ID on the server-side bridge, and track licence information should be checked before reuse.

i
Why Nuclear is not a website provider

Nuclear's plugin API is for the running desktop app. It does not provide a public hosted catalogue and browser-stream API for all TuneWave visitors. Audius, Free To Use, and the connected open audio catalogues are the supported web sources instead.

✓
Identify music you hear

Records up to 10 seconds from your microphone and asks the configured recognition service to identify it. This requires microphone permission and a valid recognition service credential.

✓
Listening controls

Lock-screen and headset controls appear when your browser/device supports Media Session.

✓
Local library

Favorites, recent tracks, and playback position are saved in this browser only.

Song availability and rights vary by provider. Funkwhale instances are independently operated and may restrict anonymous access; a public API response does not guarantee any particular song or license. Check each source page and track licence. Jamendo’s API terms permit non-commercial use by default; commercial/ad-supported projects must request terms from Jamendo. Internet Archive, Wikimedia Commons, and ccMixter results should be checked against each source’s rights page. Radio Browser results are live station streams, not individual track records. Free To Use streams are provided by its official API without credentials; its licence conditions still apply. Openverse uses anonymous access by default. The Archive is not a catalogue of current commercial hits. Nuclear remains a desktop companion rather than a provider inside TuneWave. TuneWave does not add its own ads, but cannot guarantee third-party streams are always available or ad-free. Background and lock-screen controls depend on browser/device support.
